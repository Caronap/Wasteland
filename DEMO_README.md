# Wasteland Frontier Demo

Wasteland Frontier is a voxel survival prototype built as a Luanti game.

## What You Need

- Luanti installed on your computer: https://www.luanti.org/
- This demo folder copied into Luanti's `games` directory.

## Install

1. Unzip the demo package.
2. Copy the `luanti_wasteland_game` folder into your Luanti games directory.

Common locations:

```text
macOS: ~/Library/Application Support/luanti/games/
Windows: C:\Users\<you>\AppData\Roaming\luanti\games\
Linux: ~/.luanti/games/
```

For older Minetest installations, use the matching `minetest/games` directory.

## Play

1. Open Luanti.
2. Create a new world.
3. Select `Wasteland Frontier` as the game.
4. Start the world.

## Useful Commands

Open chat in-game and run:

```text
/wf_new_start
/wf_reset
/bag
/quest
```

`/wf_new_start` resets the starter experience.
`/wf_reset` rebuilds the central ruined district.
`/bag` opens the custom inventory.
`/quest` refreshes the quest tracker.
